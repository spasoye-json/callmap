# The map file is committed to the repo

The map lives in a file inside the repo it describes, so it travels with git, survives a branch switch, and a teammate can read it without installing the app.

The known cost is a business one, recorded when the decision was made: a team gets sharing for free, so the app itself has to earn the seat through the review scene rather than through access to the map. The alternative, holding the map in a service, would protect the seat and break the local-first promise at the same time.
